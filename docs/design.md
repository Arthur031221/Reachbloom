# Reachbloom design

The map answers one question: where could I get from this place at this time?

Deep slate frames the controls, paper tones keep the map legible, amber marks Origin A, teal marks Origin B and purple marks shared reach. Route colors come from the timetable. No official agency logo is used.

A floating control panel keeps the map visible. Dark mode dims the panel and map together. The travel budget sits above the map so changes can be read alongside the result. Pin dragging and map transitions explain which place the query uses. Reduced motion preferences disable animated map transitions.

Rounded headings, system body text and tabular times keep dense timetable controls readable. On a phone, the controls become a bottom sheet with the map above. The language selector remains available without horizontal scrolling.

The map labels vehicle positions as scheduled and keeps the straight line walking caveat beside the result. The export includes the same caveat and attribution. These choices keep the input assumptions visible when a view is shared.
